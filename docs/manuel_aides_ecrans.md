# Aides des écrans (répertoire pour le futur manuel d'utilisation)

Ce fichier conserve, tels quels, les textes des anciennes bulles « ? » (❔) de l'application, écran par écran. Les bulles sont retirées de l'interface (charte graphique : plus de « ? ») ; une ligne d'information (ou un texte sous le champ) n'est gardée à l'écran que lorsqu'elle évite une erreur de saisie ou un effet inattendu. Tout le reste vit ici, pour écrire le manuel d'utilisation. Rien n'est perdu.

Convention : pour chaque bulle, le **titre** de la bulle, l'endroit de l'écran où elle se trouvait, puis son **texte complet** sans modification. « mobile » = écran de l'appli mobile ; « mobile + PC » = même rendu en mode bureau.

### Bilan de lactation

*Emplacement : Haut de l'écran.*  
*Décision : Bulle supprimée ; le texte n'est conservé que dans ce répertoire.*

> Vue troupeau de la campagne. Litrage total, brebis passées à la traite et brebis présentes sont calculés automatiquement (tank de Production laitière, contrôles laitiers, entrées/sorties) mais restent modifiables si besoin — une correction manuelle est signalée ("Valeur corrigée") et n'est jamais écrasée automatiquement, un bouton permet d'y revenir à tout moment. Campagne sélectionnée explicitement, jamais présumée être la campagne en cours d'Ovilog.

## Nouveau lot de recherche (critères d'échographies) — mobile

### Critères d'échographie

*Emplacement : Champ « Critères d'échographie (facultatif) ».*  
*Décision : Bulle remplacée par une ligne d'information à l'écran : « Dans un groupe : « ou » ; entre groupes : « et ». Sans critère, aucune brebis n'est présélectionnée. »*

> Choisis un ou plusieurs critères pour présélectionner des brebis ci-dessous, d'après leur DERNIÈRE écho de la campagne choisie. Dans un groupe : « ou ». Entre groupes : « et ». Tu peux ensuite ajuster la sélection à la main ou au bip. Sans critère, la sélection reste vide.

## Import bilan de lactation (SIEOL) — mobile

### Format du fichier

*Emplacement : Champ « Fichier CSV ».*  
*Décision : Bulle supprimée ; le texte n'est conservé que dans ce répertoire.*

> Fichier CSV (;) avec les colonnes numero_visuel_sieol;num_lactation;ref;ano_repro;date_mise_bas;taille_portee;mode_repro;ano_lact;lact_totale;duree_traite;indice_cumule;classe_par_quart;index_asc;cd_asc. Dates JJ/MM/AAAA, décimales à virgule.

## Import contrôle laitier SIEOL — mobile

### Format du fichier résumé

*Emplacement : Champ « Fichier résumé ».*  
*Décision : Bulle supprimée ; le texte n'est conservé que dans ce répertoire.*

> Fichier résumé par contrôle (;), 1 ligne par contrôle -- colonnes repérées par leur en-tête (num_controle, date_controle, lait_total, lait_controle, nb_brebis, nb_ech, coef_ac, nb_antenaises, nb_adultes, lait_antenaises ou moy_jour_antenaises_ml, lait_adultes ou moy_jour_adultes_ml, moy_jour_troupeau_ml si disponible) : l'ordre et les colonnes en plus n'ont pas d'importance. Dates JJ/MM/AAAA, décimales à virgule.

### Format du cahier de contrôle

*Emplacement : Champ « Fichier cahier de contrôle ».*  
*Décision : Bulle supprimée ; le texte n'est conservé que dans ce répertoire.*

> Cahier de contrôle détaillé (;), 1 ligne par brebis -- colonnes repérées par leur en-tête (numero_visuel_sieol, ctl1_ml/ctl1_anomalie, ctl2_ml/ctl2_anomalie, ctl3_ml/ctl3_anomalie, ano_lact, num_lactation, ref, lact_moyen, classe_par_quart) : l'ordre et les colonnes en plus n'ont pas d'importance -- ano_repro/date_mise_bas/taille_portee/mode_repro, si présentes, sont ignorées (aucune mise bas n'est créée depuis cet écran).

*Emplacement : Champ « Fichier modèle Ovilog ».*  
*Décision : Bulle supprimée ; le texte n'est conservé que dans ce répertoire.*

## Import nouveaux animaux — mobile

### Format du fichier

*Emplacement : Champ « Fichier modèle Ovilog ».*  
*Décision : Bulle supprimée ; le texte n'est conservé que dans ce répertoire.*

> Fichier .xlsx basé sur Modele_Nouveaux_Animaux.xlsx -- 3 onglets Brebis/Béliers/Agnelles, en-têtes en ligne 4, données à partir de la ligne 5. Crée les fiches qui n'existent pas encore (numéro EID complet, 11 chiffres) et complète les numéros SIEOL/la généalogie des fiches déjà existantes. Un EID déjà présent dans Ovilog n'est jamais dupliqué.

## Import contrôle laitier (fichier modèle) — mobile

### Format du fichier

*Emplacement : Champ « Fichier modèle Ovilog ».*  
*Décision : Bulle supprimée ; le texte n'est conservé que dans ce répertoire.*

> Fichier .xlsx basé sur Modele_Controle_Laitier.xlsx, onglet "Contrôle laitier" -- ligne 4 : date de chaque contrôle (une fois par colonne) ; à partir de la ligne 6 : numéro EID (11 chiffres) ou numéro SIEOL (court ou long), puis quantité en mL et/ou code anomalie (format "quantité/code", ex: 1400/01, ou code seul comme 09 quand rien à mesurer) des contrôles 1/2/3. Une colonne sans date valide en en-tête est considérée comme un contrôle pas encore réalisé et entièrement ignorée.
